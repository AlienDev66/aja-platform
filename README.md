# AJA Digital

Infraestrutura tecnológica da Associação dos Juízes de Angola.

## Arranque

```bash
cd web
bun install
bun dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Rotas

| Rota | Descrição |
|------|-----------|
| `/` | Landing institucional (produto) |
| `/entrar` | Login |
| `/app` | Painel + cartão digital |
| `/app/comunicados` | Connect + WhatsApp |
| `/app/eventos` | Calendário e inscrições |
| `/app/quotas` | Histórico e pagamento |
| `/app/academy` | Cursos + biblioteca |
| `/app/governance` | Assembleias e atas |
| `/app/protect` | Apoio confidencial |
| `/app/perfil` | Dados do associado |
| `/app/notificacoes` | Alertas |
| `/admin` | Painel da Direcção |
| `/admin/comunicados/novo` | Publicar (+ opção WA) |
| `/admin/associados` | Gestão de membros |

## Princípios

- Sistema **associativo** — sem processos judiciais
- **WhatsApp coexiste** como canal de distribuição; a plataforma é a fonte oficial
- Dados e código: propriedade da AJA
